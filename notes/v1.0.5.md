## 本次更新

1.0.4 的持续响铃有个明显的收尾漏洞：**除了「知道了」和「+1 分钟」，别的操作都停不掉铃声**。这一版把它补上了。

### 修复

- **点「完成」不再让铃声继续响**：之前把一步勾成完成，计时结束了，铃声还在响。现在暂停、完成、删除这锅，都会一并停掉铃声——你处理完的东西不该继续吵
- **划掉通知也能停铃**：Android 13 起前台服务的通知可以被划走。划掉之后「知道了」按钮跟着消失，铃声就再也没有停止入口，只能强杀 App。现在划掉等同于点「知道了」
- **响铃开头不再「重音」一下**：通知渠道自身的声音和循环播放的铃声会各响一次，听起来像卡了一下。现在渠道侧静音，只保留循环铃声

### 下载

| 文件 | 大小 | 适用 |
|---|---|---|
| `StoveSide-1.0.5.apk` | 9.6 MB | Android 7.0 (API 24) 及以上 |
| `SHA256SUMS` | 87 B | 校验：`sha256sum -c SHA256SUMS` |

**从 1.0.4 升上来的用户**：签名相同，直接覆盖安装即可，数据保留。如果你的手机已经建过旧的响铃通知渠道，这一版换了新渠道，系统会把提醒设置重置为默认——之前的把关过的需要重新确认一次。

## What's new

The persistent alarm in 1.0.4 had an obvious gap: **only "Got it" and "+1 min" could stop it**. This release closes that.

### Fixed

- **Completing a step no longer leaves the alarm ringing**: ticking a step off ended the timer but the ring kept going. Pausing, completing, or deleting a cook now stops the alarm too — something you have already dealt with should not keep making noise
- **Swiping the notification away now stops it**: since Android 13, a foreground service notification can be swiped away. That also removed the "Got it" button, leaving no way to stop the ring short of force-killing the app. Swiping away now counts as "Got it"
- **No more doubled sound at the start**: the notification channel's own sound played once on top of the looping alarm, which sounded like a stutter. The channel is now silent and only the looping alarm plays

| `SHA256SUMS` | 87 B | Verify with `sha256sum -c SHA256SUMS` |

**Upgrading from 1.0.4**: the signature is unchanged, so install straight over it, data preserved. If your phone already created the older ringing channel, this version uses a new one, so Android resets the alert settings to default — re-confirm them once if you had changed them.
