## 本次更新

1.0.6 的到点弹窗有个收尾没接上：从通知栏确认过之后，回到 App 还会被同一个到点再问一次。这一版把它补上。

### 修复

- **通知栏点过「知道了」，回 App 不再重复弹**：确认记录原来只记在弹窗那条路径上，下拉通知确认、或者直接把通知划走，都不算数。现在两条通道共用同一份记录，哪个入口确认过，另一个就不会再问

### 其他

- 补齐 CHANGELOG 底部的版本链接（1.0.6 的条目此前仍被归在 Unreleased 下），交接文档的发布状态与提交哈希同步到当前 HEAD

## What's new

The in-app dialog added in 1.0.6 had one loose end: after acknowledging from the notification shade, the same expiry would ask again inside the app. This release closes it.

### Fixed

- **Acknowledging from the notification shade no longer triggers a second dialog**: the acknowledgement used to be recorded only when you dismissed the dialog itself, so tapping "Got it" on the notification — or swiping the notification away — did not count. Both paths now share one record, so whichever entry point you use, the other stays quiet

### Also

- Changelog version links are filled in again (the 1.0.6 entry was still being counted under Unreleased), and the handoff document now matches the current HEAD

### Downloads

| File | Size | Requires |
|---|---|---|
| `StoveSide-1.0.7.apk` | 9.6 MB | Android 7.0 (API 24) or newer |
| `SHA256SUMS` | 87 B | Verify with `sha256sum -c SHA256SUMS` |

**Upgrading from 1.0.6**: the signature is unchanged, install straight over it, data preserved. The database schema is unchanged.
