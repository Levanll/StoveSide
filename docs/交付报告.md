## 三、Bug 修复记录（开发期发现并修复）

| 问题 | 根因 | 修法 |
| --- | --- | --- |
| 版本比较误判 | GitHub tag 只有 versionName，无 versionCode | 改用语义版本比较 + 4 条单测 |
| 到点后步骤被打回 pending | TimerService 提醒时改了状态 | 只提醒不改状态，去重键改 (stepId, dueAt) |
| 发布脚本无法推送 | 凭据未注入 git | GIT_CONFIG 凭据 helper，token 不进 URL/进程参数/磁盘 |
| Release 资产找不到 | APK 未拷进暂存目录 | collect_assets 先 copy 再上传 |
| git tag 失败 | 无 committer identity | 环境变量注入 GIT_AUTHOR/COMMITTER |

## 四、安全与脱敏核查

- `scripts/scan_secrets.py` 在发布前 6 个步骤各跑一次，全部 OK
- 仓库跟踪文件中**无** keystore / .jks / local.properties / .gh_token（已用 `git ls-files` 核验）
- Token 仅从 `lanpulse/.gh_token` 读取，全程只打印「前缀类型 + 长度」，不打印内容
- `--include-ignored` 扫描会命中 `keystore/keystore.properties` 的口令字段——符合预期，该文件本就 gitignore，用于自查
- 错误信息经 `_scrub()` 过滤，任何 git 输出里的 token 都会被替换成 `<redacted>`

## 六、备份与回滚

```powershell
# 高危修改前
.\scripts\snapshot.ps1

# 预览还原（默认不落盘）
.\scripts\snapshot.ps1 -Restore F:\deepseek-harness\_archive\20261112-0136-cooktimer

# 实际还原
.\scripts\snapshot.ps1 -Restore <快照目录> -Force
```

App 内数据：导入前自动写入 `files/backups/auto-<时间戳>.json`，保留最近 20 份。

## 七、构建与发版命令

```bash
# 构建（离线可用）
export GRADLE_USER_HOME=F:/android-dev/gradle-home
F:/android-dev/gradle-dist/gradle-8.9/bin/gradle --offline -Pkotlin.compiler.execution.strategy=in-process assembleRelease

# 发布（改版本号后）
D:/python/python.exe scripts/publish.py --public --yes
```

> **注意**：本机 Gradle 的 Kotlin 编译 worker 在此环境会因 JVM agent 问题失败，
> 必须加 `-Pkotlin.compiler.execution.strategy=in-process`。这是环境限制，不是项目问题。
