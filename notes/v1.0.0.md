## 本次更新

首版发布。多流程并行计时、步骤备注、同菜多份独立追踪、粘贴文本自动拆分、中英双语、导出导入与应用内更新，一次到位。

### 新增

- **多流程并行计时**：同时跑多个烹饪流程，每个步骤独立计时、独立到期，互不阻塞
- **模板与实例分离**：食谱是模板，每次下厨开一份实例，进度与备注各记各的
- **步骤备注**：每个节点可写备注，实例内的改动不回写模板
- **粘贴文本拆分**：粘贴菜谱原文，自动按行与序号切步骤并识别时长
- **中英双语**：界面文案双语，语言选择持久化，下次启动沿用
- **导出与导入**：全量数据导出为单文件 JSON，导入前自动快照
- **应用内更新**：检查 GitHub Releases，下载到应用私有目录后由用户确认安装

## What's new

The first release. Parallel timers, per-step notes, batch tracking, paste-to-steps, bilingual UI, backup, and in-app updates — all in one go.

### Added

- **Parallel timers**: run several cooking flows at once; every step counts down and expires independently
- **Template vs session**: a recipe is a template; each cook is a session that keeps its own progress and notes
- **Step notes**: every node takes a note; session edits never write back to the template
- **Paste-to-steps**: paste recipe text and get timed steps split by line and numbering
- **Bilingual UI**: Chinese and English copy with a persisted language choice
- **Export / import**: full backup as a single JSON file, with an automatic snapshot before import
- **In-app update**: checks GitHub Releases, downloads into app-private storage, installs only after confirmation

### Downloads

| File | Size | Requirements |
|---|---|---|
| `app-release.apk` | 9.6 MB | Android 7.0 (API 24) and above |
| `SHA256SUMS` | 83 B | Verify with `sha256sum -c SHA256SUMS` |

Install straight over any previous build; no uninstall needed.
