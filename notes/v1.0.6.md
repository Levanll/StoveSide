## 本次更新

这一版补上了两处「明显该有但没有」的体验：到点在 App 里也能停铃，设置页的选中项终于能一眼看出来。

### 新增

- **到点后在 App 内弹窗**：以前到点只有通知栏能停铃，人在前台看着屏幕反而要下拉通知。现在不管停在「在煮」「食谱」还是「设置」，时间一到都会弹出对话框，直接有「+1 分钟」和「知道了」
- **「知道了」不改状态**：点掉弹窗只停铃，这一锅仍然是「00:00 已到点」，红色标记还在原位。要续时间点「+1 分钟」，要收尾就点勾——怎么处理由你决定
- **试听也走同一个弹窗**：设置页的试听不再只响在通知栏，和真实到点看到的是同一个界面

### 改进

- **设置页选中项改成填充高亮 + 勾选图标**：原来的写法把「已选中」画成灰色禁用态，未选中项反倒是亮边框，读起来和「亮 = 已选」正好相反。现在选中的是填色带勾的那一个
- **超时提示不再吓人**：隔夜才回来看，弹窗显示「早就到点了」，不会出现「已过 236 小时」这种像 bug 的数字；一小时内仍然给到秒的精确时长

| `SHA256SUMS` | 87 B | 校验：`sha256sum -c SHA256SUMS` |

**从 1.0.5 升上来的用户**：签名相同，直接覆盖安装，数据保留。这一版没有改数据库结构，已有的食谱和下厨记录不会受影响。

## What's new

Two gaps that were plainly worth closing: you can now stop an alarm inside the app, and the selected option in Settings finally looks selected.

### Added

- **In-app dialog when a timer runs out**: before this, only the notification shade could stop the alarm, so even with the app open you had to pull it down. Now the dialog appears on every screen — Cooking, Recipes or Settings — with "+1 min" and "Got it" right there
- **"Got it" leaves the step alone**: dismissing only stops the alarm. The step still reads "00:00 overdue" and its red marker stays where it was, so you can extend it or tick it off as you see fit
- **The test alarm uses the same dialog**: "Try it" in Settings no longer sounds only as a notification; it shows exactly what a real expiry looks like

### Improved

- **Selected options in Settings are filled and ticked**: the old code drew the selected option as a greyed-out disabled button while the unselected ones stayed bright, the opposite of how people read "bright means selected". The chosen one is now the filled, ticked chip
- **No more absurd overdue numbers**: come back the next day and the dialog says "Due a while ago" instead of something that looks like a bug. Within the first hour you still get the exact duration
