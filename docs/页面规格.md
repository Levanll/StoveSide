# StoveSide 页面规格

> 三屏结构：在煮 / 食谱 / 设置。以下为每个屏的信息层级与交互约束。

## 一、在煮（CooksScreen）

**目标**：一眼看出"哪份食物走到哪一步"。

| 区域 | 内容 | 规则 |
| --- | --- | --- |
| 顶部 | 「在煮的东西」+ 「N 个流程 · 每秒刷新」 | 副标题实时反映数量 |
| 快捷开火 | 最多 3 个食谱的胶囊按钮 | 点一下即开新实例，无需二次确认 |
| 实例卡片 | 食谱名 + 实例编号（#1 / #2） | 同一食谱的多份必须可区分 |
| 卡片副标题 | 「已完成 n/m 步」 | 进度是可追溯性的直接体现 |
| 步骤行 | 序号圆点 + 标题 + 备注 + 剩余时间 + 操作 | 见下方状态规则 |
| 空态 | 锅 emoji + 「先建一份食谱，再开火」 | 引导而不是空白 |

**排序规则**（关键）：有运行中计时的置顶 → 按最短剩余时间升序 → 其余按创建时间倒序。
效果是"最紧急的那锅永远在最上面"。

**步骤状态视觉**：

| 状态 | 圆点 | 时间显示 | 按钮 |
| --- | --- | --- | --- |
| pending | 浅灰褐底 + 序号 | 总时长「40 分」 | ▶ 开始 |
| running | 浅橙底 + 序号 | 倒计时「04:12」，<60s 时变红 | ⏸ 暂停 |
| done | 主色实心 + 白勾 | 总时长，文字变灰 | 无 |

## 二、食谱（RecipesScreen / RecipeEditorScreen）

**列表**：卡片 = 菜名 + 备注 + 开火按钮 + 删除。右下角 FAB「新建食谱」。

**编辑器**（关键交互）：

1. 菜名、整体备注、**粘贴区**、步骤列表；
2. 粘贴区可折叠，避免默认占屏；
3. 「解析预览」→ 显示识别出的步数与每步时长，「采用 N 步」一次性填入草稿；
4. 每个步骤卡片可改标题、分钟数、备注，改动实时进入草稿；
5. 分钟数留空 = 不计时（如「腌制过夜」这类无意义倒计时）；
6. 保存按钮在草稿为空时禁用。

**解析容错**：识别不出时长的行仍然保留为标题，不会被静默丢弃。

## 三、设置（SettingsScreen）

四个分区，自上而下：

| 分区 | 内容 | 说明 |
| --- | --- | --- |
| 语言 | 中文 / English 胶囊 | 立即生效并写盘，下次启动沿用 |
| 数据 | 导出备份 / 导入恢复 | 导入前自动快照，失败自动还原 |
| 版本更新 | 检查更新 / 下载到手机 | 下载到应用私有目录；安装需系统授权 |
| 关于 | 版本号 + 「本地计时，不上传任何数据」 | 隐私承诺写在明面 |

**更新流程**：检查 → 显示更新说明 → 下载 → 用户点「安装」→ 若未授权则跳转系统设置 → 返回后再次点击安装。
任何一步失败都在原地显示原因，不静默。

## 四、通用规范

- 底部导航固定三 tab，不隐藏；
- 所有破坏性操作（删除食谱/实例）直接执行，不做二次确认——数据可导出，用户可自行备份；
- 所有 Toast/提示文字用 `I18n.t` 双语；
- 圆角：卡片 16–18dp，按钮/胶囊 999dp，输入框跟随 Material3 默认；
- 间距：屏幕边距 16dp，卡片内边距 14dp，元素间距 8–12dp。
